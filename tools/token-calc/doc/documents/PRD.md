## 1. 产品概述

多模态 Token 计算器与模型计费工具 —— 支持文本、图片、语音、视频四类输入的 Token 估算，并基于可配置的模型计费规则实时计算调用费用。

- 目标用户：AI 应用开发者、Prompt 工程师、产品经理、成本预估人员
- 解决问题：在调用大模型前预估 Token 消耗与费用，避免超支与误算
- 市场价值：作为开发与算账的"前置仪表盘"，降低多模态应用的试错成本

## 2. 核心功能

### 2.1 用户角色
| 角色 | 使用方式 | 核心权限 |
|------|---------|---------|
| 普通用户 | 直接打开网页 | 输入多模态内容、查看 Token 与费用、管理本地模型库 |

### 2.2 功能模块
1. **计算工作台**：多模态输入区 + Token 实时统计 + 费用计算结果
2. **模型管理**：内置常用模型库 + 自定义模型 + 计费规则配置
3. **历史记录**：本地保存历次计算结果，支持对比与导出

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|---------|---------|---------|
| 计算工作台 | 文本输入 | 支持长文本粘贴、字符/词数实时统计、按编码估算 Token |
| 计算工作台 | 图片输入 | 支持上传/拖拽多张图片，按分辨率计算 Token |
| 计算工作台 | 语音输入 | 上传音频文件，按时长计算 Token |
| 计算工作台 | 视频输入 | 上传视频文件，按帧采样 + 时长计算 Token |
| 计算工作台 | 模型选择 | 下拉选择当前计费模型，切换即重算费用 |
| 计算工作台 | 结果面板 | 分模态 Token 明细 + 总 Token + 输入/输出费用 |
| 模型管理 | 模型列表 | 展示内置与自定义模型，支持启用/禁用 |
| 模型管理 | 模型编辑 | 编辑名称、模态支持、输入/输出单价、计费方式 |
| 历史记录 | 记录列表 | 时间、模型、Token 数、费用，支持删除与导出 JSON |

## 3. 核心流程

用户进入工作台 → 选择目标模型 → 输入文本/图片/语音/视频 → 系统分模态估算 Token → 汇总总 Token → 按模型计费规则计算输入费用 → 用户可预估输出 Token 得到输出费用 → 查看总费用 → 可选保存到历史记录

## 4. 用户界面设计

### 4.1 设计风格
- **主题方向**：数据天文台（Data Observatory）—— 深空暗色背景 + 青蓝主色 + 琥珀金强调色，营造精密科学仪器的氛围
- **主色**：深炭黑 `#0A0E14` / 深海蓝 `#0F1722` 背景；青蓝 `#22D3EE` 主强调；琥珀金 `#FBBF24` 用于费用高亮
- **次色**：石墨灰 `#1E2A3A` 卡片底；冷灰 `#64748B` 次要文字；翠绿 `#34D399` 成功状态
- **按钮风格**：扁平 + 微光晕，主按钮青蓝填充，次按钮描边
- **字体**：标题用 `Space Grotesk`（现代几何感），数据/代码用 `JetBrains Mono`（等宽精密感），正文用 `Inter` 备选
- **布局风格**：左侧固定侧边导航 + 右侧主工作区，工作区采用卡片网格 + 顶部汇总条
- **图标风格**：线性细描边图标（Lucide 风格），与精密仪器气质一致
- **动效**：数字滚动动画、卡片入场错落渐显、悬停光晕、Token 计数脉冲反馈

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI 元素 |
|---------|---------|---------|
| 计算工作台 | 顶部汇总条 | 总 Token 大数字 + 输入/输出费用徽章，琥珀金高亮 |
| 计算工作台 | 文本卡片 | 文本框 + 字符/词/Token 三联计数器 |
| 计算工作台 | 媒体卡片 | 上传区 + 缩略图网格 + 单项 Token 标签 |
| 计算工作台 | 模型选择条 | 模型下拉 + 模态支持图标 + 单价速览 |
| 计算工作台 | 结果面板 | 分模态明细表 + 总计行 + 保存按钮 |
| 模型管理 | 模型表格 | 名称、模态、输入价、输出价、状态开关、编辑 |
| 模型管理 | 编辑抽屉 | 表单：名称、模态勾选、计费方式、单价、固定 Token |
| 历史记录 | 记录表格 | 时间、模型、Token、费用、操作列 |

### 4.3 响应式
- 桌面优先（≥1280px）：三栏卡片网格 + 侧边导航
- 平板（768-1279px）：两栏卡片 + 顶部导航
- 移动端（<768px）：单栏堆叠 + 汉堡菜单，触控优化按钮尺寸

### 4.4 3D 场景
不适用（纯数据工具，无 3D 需求）
